# History_Crash 개발 일지

[← 3D_Model](../README.md)

고대 이집트 신전을 배경으로 한 보스전 환경과 패턴 연출 작업입니다. 같은 신전을 무언가에 잠식된 `_impe`와 정화된 `_defalt` 두 상태로 만들고, 보스 패턴 5종을 Unity에서 연출했습니다.

- **도구:** Blender(모델링·재질·애니메이션), VARCO3D(컨셉 이미지·3D 생성), Unity 6000.3 URP(배치·연출)
- **기간:** 2026-11-04 ~ (진행 중)
- **표기:** 시간은 한국 시간(KST), 면 수는 삼각면 기준
